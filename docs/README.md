# Геометрические вычисления

## Общее описание

Проект содержит набор функций для вычисления площади и периметра геометрических фигур.

Реализованы функции для следующих фигур:

* круг;
* прямоугольник;
* квадрат;
* треугольник.

Все функции принимают необходимые параметры и возвращают результат вычисления.

## Описание функций

### Круг

Файл: `circle.py`

#### `area(r)`

Вычисляет площадь круга.

**Аргументы:**

* `r` — радиус круга.

**Возвращает:**

* площадь круга.

**Пример вызова:**

```python
area(5)  # 78.53981633974483
```

#### `perimeter(r)`

Вычисляет длину окружности.

**Аргументы:**

* `r` — радиус круга.

**Возвращает:**

* длину окружности.

**Пример вызова:**

```python
perimeter(5)  # 31.41592653589793
```

---

### Прямоугольник

Файл: `rectangle.py`

#### `area(a, b)`

Вычисляет площадь прямоугольника.

**Аргументы:**

* `a` — ширина прямоугольника;
* `b` — высота прямоугольника.

**Возвращает:**

* площадь прямоугольника.

**Пример вызова:**

```python
area(5, 3)  # 15
```

#### `perimeter(a, b)`

Вычисляет периметр прямоугольника.

**Аргументы:**

* `a` — ширина прямоугольника;
* `b` — высота прямоугольника.

**Возвращает:**

* периметр прямоугольника.

**Пример вызова:**

```python
perimeter(5, 3)  # 16
```

---

---

### Треугольник

Файл: `triangle.py`

#### `area(a, h)`

Вычисляет площадь треугольника.

**Аргументы:**

* `a` — длина основания треугольника;
* `h` — высота, опущенная на основание `a`.

**Возвращает:**

* площадь треугольника.

**Пример вызова:**

```python
area(5, 4)  # 10
```

#### `perimeter(a, b, c)`

Вычисляет периметр треугольника.

**Аргументы:**

* `a` — длина первой стороны;
* `b` — длина второй стороны;
* `c` — длина третьей стороны.

**Возвращает:**

* периметр треугольника.

**Пример вызова:**

```python
perimeter(3, 4, 5)  # 12
```
